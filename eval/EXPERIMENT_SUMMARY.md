# 實驗摘要：結構化 Agent vs. ReAct — 誠實性與幻覺

> 一頁版重點。完整版見 `EXPERIMENT_REPORT.md`。

## 在測什麼

留學諮詢問答系統。核心問題：**問一所「資料庫沒有官方資料」的學校時，系統會誠實說「沒收錄」，還是編一個假答案（幻覺）？**

三個受測系統（共用同一組工具、同款 LLM，只差護欄）：

| 系統 | 生成前 Verifier | 生成後 Critic |
|---|:---:|:---:|
| **agent**（我們的系統） | ✅ | ✅ |
| **react**（純 ReAct，無護欄） | ❌ | ❌ |
| **react_critic**（ReAct + 只補 Critic） | ❌ | ✅ |

題庫 94 題：A 類 34 題（已收錄校，有標準答案）＋ E 類 60 題（20 所未收錄校，考誠實拒答）。

## 結果

**A 類（有官方資料）— 基準線：兩系統都 1.000 答對，一樣準。**

**E 類（未收錄學校，60 題）— 主結果：**

| 系統 | 誠實拒答率 | 幻覺率 | 工具/題 | 延遲(s) |
|---|:---:|:---:|:---:|:---:|
| **agent** | **1.000** | **0.000** | 2.30 | 4.79 |
| react | 0.167 | 0.550 | 4.28 | 7.94 |
| react_critic | 0.217 | **0.550** | 4.10 | 8.83 |

## 三個重點

1. **有官方資料時兩系統一樣準（A 都 1.0）**，差距全在「沒資料時怎麼辦」。
2. **純 ReAct 有 55% 的題編造假分數**，還更慢、更耗工具；agent 零幻覺、全部誠實拒答。
3. **加一道事後 Critic 幾乎沒用**：幻覺率仍 0.550（Critic 會加警告，但虛構數字仍留在答案裡，沒被移除），延遲反而更高。

## 結論

防幻覺要靠**生成前的來源控制與拒答決策（Verifier）**，不是**生成後的警告標註（Critic）**。在高風險領域，「數字根本不生成」勝過「數字還在、只加警語」。

## 侷限

只對照 ReAct 一種 baseline；幻覺以「有無報出具體分數」為代理指標；官方資料僅 5 校（部分為測試資料）。
